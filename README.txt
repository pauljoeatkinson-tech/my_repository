For my analysis I have used HR data, specifically the IBM HR Analytics Employee Attrition & Performance file. For my analysis I focussed on all Sales people, those who have attrition and those who do not in order to examine monthly income data for sales people with attrition and without attrition. I have drawn the following conclusions:

Job satisfaction among sales people does not seem to be related to monthly income. Average monthly income is $6,959. The minimum and maximum monthly incomes are $1,052 and $19,847. Finally, I've observed that monthly income for people without attrition in the Sales department exceeds monthly income for those with attrition.

The raw data is at this link https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset/data. The summarized data for the visualizations has been uploaded.

The directory structure of this project is as follows:

my_repository\munge\ - Contains a txt file which describes the transformations applied to the raw data and a txt file containing the SQL used to apply these changes.

my_repository\src\ - Contains a txt file which describes the aggregations applied to the raw data and a txt file containing the SQL used to apply these changes.

my_repository\reports\ - Contains a txt file which describes the visualizations produced using the summarized file. There is a dashboard and a histogram.
